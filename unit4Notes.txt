Topic 1: Importance and Features of Spark SQL
What is Spark SQL?
Spark SQL is a component of Apache Spark used to process and analyse structured data using SQL queries.

It lets us query data stored in Spark DataFrames using familiar SQL commands such as SELECT, WHERE, GROUP BY, and ORDER BY.

Simple example
Suppose we have an employee DataFrame with columns like ID, Department, and Salary.

We can use Spark SQL to find employees whose salary is greater than 55,000:
spark.sql("SELECT * FROM EMP WHERE salary > 55000").show()

Here, EMP is a temporary view created from the employee DataFrame


Features of Spark SQL
1. SQL query support: Supports common SQL operations such as SELECT, WHERE, GROUP BY, and ORDER BY.
2. DataFrame integration: Allows Spark DataFrames to be queried using SQL.
3. Temporary views: A DataFrame can be registered as a temporary view and then queried by name.
4. Built-in functions: Supports aggregate functions such as COUNT, MAX, MIN, and AVG.
5. Distributed execution: Spark can process data across multiple machines when running on a cluster



Topic 2: Methods to Convert RDDs to DataFrames

- Method 1: Convert an RDD using toDF()
import spark.implicits._

val data = Seq(("India", 300), ("Australia", 200))
val rdd = spark.sparkContext.parallelize(data)

val df1 = rdd.toDF() # Here the column names would be as _1 and _2 (Default column names)
df1.show()

- Method 2: Convert an RDD using toDF() with column names
val df1Named = rdd.toDF("team", "matches")
df1Named.show()

## Joins
import spark.implicits._

// Employee data
val empData = Seq(
  (1, "Aman", 10),
  (2, "Ravi", 20),
  (3, "Simran", 30)
)

val empRDD = spark.sparkContext.parallelize(empData)
val empDF = empRDD.toDF("id", "name", "deptId")

empDF.show()

// Department data
val deptData = Seq(
  (10, "IT"),
  (20, "HR"),
  (40, "Sales")
)

val deptRDD = spark.sparkContext.parallelize(deptData)
val deptDF = deptRDD.toDF("deptId", "department")

deptDF.show()

empDF.createOrReplaceTempView("EMP")
deptDF.createOrReplaceTempView("DEPT")

- Performing Joins
spark.sql("""
  SELECT EMP.name, DEPT.department
  FROM EMP
  INNER JOIN DEPT
  ON EMP.deptId = DEPT.deptId
""").show()

spark.sql("""
  SELECT EMP.name, DEPT.department
  FROM EMP
  LEFT JOIN DEPT
  ON EMP.deptId = DEPT.deptId
""").show()


spark.sql("""
  SELECT EMP.name, DEPT.department
  FROM EMP
  RIGHT JOIN DEPT
  ON EMP.deptId = DEPT.deptId
""").show()


spark.sql("""
  SELECT EMP.name, DEPT.department
  FROM EMP
  FULL OUTER JOIN DEPT
  ON EMP.deptId = DEPT.deptId
""").show()


## GROUP BY
import spark.implicits._

val empData = Seq(
  (1, "Aman", "IT", 60000),
  (2, "Ravi", "HR", 50000),
  (3, "Simran", "IT", 70000),
  (4, "Priya", "HR", 55000),
  (5, "Karan", "Sales", 45000)
)

val empRDD = spark.sparkContext.parallelize(empData)
val empDF = empRDD.toDF("ID", "Name", "Department", "Salary")

empDF.show()

empDF.createOrReplaceTempView("EMP")

- spark.sql("""
  SELECT Department, COUNT(ID)
  FROM EMP
  GROUP BY Department
""").show()

- spark.sql("""
  SELECT Department, AVG(Salary)
  FROM EMP
  GROUP BY Department
""").show()

## Order By

spark.sql("select * from EMP order by salary").show()

spark.sql("select * from EMP order by salary DESC").show()

## SQL Wildcards

1. Names starting with A:
spark.sql("SELECT * FROM EMP WHERE Name LIKE 'A%'").show()

Matches Aman, Arjun, Anu, and Avi.

2. Names ending with a:
spark.sql("SELECT * FROM EMP WHERE Name LIKE '%a'").show()

Matches Riya.

3. Names containing r:
spark.sql("SELECT * FROM EMP WHERE Name LIKE '%r%'").show()

Matches Arjun.
