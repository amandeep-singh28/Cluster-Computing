# Scala
It is the programming language of the Apache Spark
Scala is a programming language that combines Object-Oriented Programming (OOP) and Functional Programming (FP).

- Why Scala?
Because Spark programs can be written using Scala.

- REPL
It stands for:
    R — Read
    E — Evaluate
    P — Print
    L — Loop
It is an environment where we enter one command, Scala evaluates it immediately, displays the result/error, and waits for the next command.

Example:
    scala> 10 + 20
Scala immediately evaluates it:
    res0: Int = 30

- Why is REPL useful?
Instead of writing:
    program → compile → run → check result
you can simply do:
    command → result

# val, var & Type Inference
Scala gives us two important ways to create these bindings:

          Variables
             │
       ┌─────┴─────┐
       ▼           ▼
      val         var
   Immutable    Mutable

- val — Immutable
Meaning:
    val creates an immutable binding.
Once you assign a value, you cannot reassign that name to another value.

Example:
    val age = 21
    println(age)
    age = 25 // Error

- var — Mutable
var is the opposite.
var creates a mutable binding whose value can be changed later, provided the new value is compatible with its type.
Example:
    val age = 21
    println(21) // 21
    age = 25
    println(25) // 25 (No error)

- val vs var
This is a must-remember CA table:

val	                    var
Immutable	            Mutable
Cannot be reassigned	Can be reassigned

- Type Inference
Look at this:
    val x = 10
We didn't write:
    val x: Int = 10

So how does Scala know x is an Int?
That's where Type Inference comes in:
    Type inference allows the Scala compiler to determine the type of a value from the expression assigned to it.

- Explicit Type Declaration
val age: Int = 21
val name: String = "Amandeep"
var marks: Double = 85.5

Without explicit type:
    val age = 21
Scala figures out:
    age → Int
With explicit type:
    val age: Int = 21
You tell Scala:
    age → Int

# Scala Data Types & Literals
(i) Int
val age: Int = 21

(ii) Long
val population: Long = 84561355L

(iii) Float
val price : Float = 25.5F

(iv) Double
val price : Double = 25.5

(v) Char -> Single Quotes
stores one Character 
val grade : Char = 'A'
'A'    → Char
"A"    → String

(vi) Boolean
Stores only two values: true/false
val isStudent : Boolean = true
or
val result = 10 > 5 // result -> Boolean

(vii) String
Used for text
val name: String = "Amandeep"

(viii) Unit -> No meaningful value
Unit represents no meaningful return value
It is similar to void
For example:
    def display(): Unit = {
        println("Hello")
    }
The function performs an action but doesn't return a useful value.

- What are Literals
Data type
Tells us what kind of data something is.

Literal
The actual value written directly in the program.

Example:
    val age: Int = 21

Here:
    Int → data type
    21  → literal
