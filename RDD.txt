# RDD - Resilient Distributed Dataset
An immutable, distributed collection of elements that can be processed in parallel.

- Resilient (Fault Tolerant)
It means that it can revover lost data.

- Distributed
Data is divide into partitions and processed across multiple nodes / computers

- Dataset
Collection of data

- Why RDD
Imagine you have:
    10 million records

Processing everything on one machine can be slow.
Spark can divide the data:
             RDD
              │
       ┌──────┼──────┐
       ↓      ↓      ↓
   Partition Partition Partition
       ↓      ↓      ↓
     Node 1  Node 2  Node 3

These partitions can be processed in parallel.
That's one of the major reasons Spark is fast.

- Five main characteristics of RDD
1. Immutable (Once an RDD is created, it cannot be changed.)
2. Distributed
3. Fault Tolerant
4. Lazy Evaluation
5. Parallel Processing

- Fault Tolerant (Resilient) - IMP
Suppose:
    Partition 1 → A B
    Partition 2 → C D
    Partition 3 → E F
If Partition 2 is lost:
    Spark can recreate it using lineage
What is lineage?
Lineage is basically the record of how an RDD was created from previous RDDs.

For example:
RDD1
 ↓ filter()
RDD2
 ↓ map()
RDD3

Spark remembers this relationship.
If RDD3 data is lost, Spark can use the previous steps to recreate the required data.

- Note:
Lineage → helps Spark recover lost RDD partitions.

# Lazy Evaluation
RDD transformations are not executed immediately.

For example:
    val rdd = sc.parallelize(1 to 10)
    val even = rdd.filter(x => x % 2 == 0)

You might think filter() immediately processes the numbers.
It doesn't.

Spark remembers:
    "Whenever execution is needed,
    apply filter to this RDD."

Actual execution happens when we call an action.
For example:
    even.collect()

# How can we create an RDD?
There are particular three methods to create an RDD:
1. parallelize()
2. textFile()
3. DataFrame.rdd

(i) parallelize()
We can create RDD from collections also but we have to use "sc"
For example:-
val r1 = sc.parallelize(
    Seq(("A",1),("B",2),("C",3))
)
r1.collect().foreach(println)

(ii) textFile()
Used to create an RDD by reading a text filter
val r2 = sc.textFile("D:\data.txt")
    Each line of the text file becomes an element of the RDD.

(iii) DataFrame - RDD
val r4 = spark.range(20).toDF().rdd

Step 1
spark.range(20)
Creates:
    0, 1, 2, ..., 19

Step 2
.toDF()
Converts it into a DataFrame.

Step 3
.rdd
Converts the DataFrame into an RDD.

So:
    spark.range(20)
        ↓
        DataFrame
        ↓ .rdd
        RDD

- Partitions (Important)
RDD data is divided into partitions
val rdd = sc.parallelize(Array(1, 2, 3, 4), 3)

- Transformations vs Actions
RDD operations are divided into:
    - Transformations
    - Actions

-> Transformations
A transformations creates a new RDD
For example:-
map()
flatMap()
filter()
distinct()
union()
groupByKey()
sortByKey()
join()
coalesce()

For example:-
    val x = sc.parallelize(1 to 10)
    val y = x.filter(z => z % 2 == 0)
Here:
x
↓ filter()
y

A new RDD y is created.
And because it's a transformation:
It is evaluated lazily.

-> Action
An action returns a result or triggers execution.

Examples from your notes:
    collect()
    foreach()
    count()
    first()

Example:
val y = x.filter(z => z % 2 == 0)
y.collect()

Here:
    filter()
    ↓
    Transformation
    ↓
    collect()
    ↓
    Action
    ↓
    Execution
